# Задача: security-аудит и починка обработчика загрузок

`uploads.py` обслуживает загрузку и раздачу файлов для недоверенных
клиентов. Код написан торопливо и содержит НЕСКОЛЬКО независимых
уязвимостей разного типа. Твоя задача:

1. Найти ВСЕ уязвимости (их больше одной; полный список не даётся —
   полнота поиска и есть часть задачи).
2. Закрыть каждую, не сломав легитимные сценарии.
3. В финальном ответе перечислить каждую найденную уязвимость: класс,
   строка, как эксплуатировалась, как закрыта.

## Легитимные сценарии, которые обязаны продолжать работать

- `save_upload(root, name, data)` сохраняет файл под `root/uploads/` и
  возвращает путь; имена вида `report.pdf`, `фото 2026.jpg`, `a_b-c.txt`.
- `fetch(root, name)` возвращает байты ранее сохранённого файла.
- `extract_bundle(root, zip_path)` распаковывает клиентский zip в
  `root/uploads/bundle/` (архив приходит от клиента!).
- `log_access(root, client_id, name)` дописывает строку аудита в
  `root/access.log` — по одной записи на строку; целостность лога важна:
  по нему проводят расследования.
- `check_token(stored, presented)` — сверка секретного токена доступа.

## Ограничения

Только stdlib. Публичные сигнатуры функций не менять. Поведение при атаке —
`PermissionError`/`ValueError` (осмысленно), не тихий успех.

## Готовность

Явно напиши, что готово; полнота списка уязвимостей будет проверена — если
что-то из реально присутствующего в коде не найдено и не закрыто, задача не
засчитывается, поэтому доказывай себе полноту, а не только чини очевидное.
