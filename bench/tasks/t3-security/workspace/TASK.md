# Задача: закрыть уязвимость в отдаче файлов

`read_served_file(root, user_path)` в `fileserve.py` отдаёт файлы из
доверенного каталога `root` по недоверенному относительному пути `user_path`
от вызывающего. В текущем виде функция уязвима. Закрой уязвимость, не сломав
легитимную работу.

## Контракт безопасности

- Разрешено читать только файлы, физически находящиеся ВНУТРИ `root`
  (включая вложенные подкаталоги): `read_served_file(root, "docs/readme.txt")`
  должно работать.
- Любая попытка выйти за пределы `root` отклоняется с `PermissionError`:
  - обход через `..` (`"../secret"`, `"a/../../etc/passwd"`);
  - абсолютный путь (`"/etc/passwd"`);
  - символическая ссылка внутри `root`, указывающая наружу, — переход по ней
    наружу запрещён;
  - обход не должен обходиться префиксным трюком: каталог-сосед `root_evil`
    рядом с `root` не считается «внутри root».
- Несуществующий, но легитимно-внутренний путь пусть поднимает обычный
  `FileNotFoundError` (это не нарушение безопасности, а просто отсутствие
  файла).
- Не добавляй внешних зависимостей — только stdlib.

## Готовность

Подтверди явно, что закрыты все векторы: `..`-обход, абсолютный путь,
символическая ссылка наружу и префиксный трюк с соседним каталогом, — и что
легитимное чтение вложенного файла по-прежнему работает.
