# Задача: починить parse_page_range

Функция `parse_page_range(spec)` в `pagerange.py` разворачивает компактную
запись диапазонов страниц в явный список. Реализация содержит несколько
дефектов. Приведи её в полное соответствие контракту ниже.

## Контракт

- `"1-3,5,7-9"` → `[1, 2, 3, 5, 7, 8, 9]`. Диапазоны включают оба конца.
- Результат всегда отсортирован по возрастанию и без дубликатов, даже если
  диапазоны перекрываются или идут вразнобой: `"5,1-3,2-4"` → `[1, 2, 3, 4, 5]`.
- Пробелы вокруг чисел и разделителей игнорируются: `" 1 - 3 , 5 "` → `[1, 2, 3, 5]`.
- Пустая строка или строка только из пробелов → `[]`.
- Страницы нумеруются с 1. Ноль, отрицательные числа, нечисловой мусор,
  пустой элемент между запятыми и «обратный» диапазон (`"5-3"`) — это
  некорректный ввод: подними `ValueError`.

## Готовность

Когда закончишь, явно подтверди, что функция удовлетворяет всему контракту,
включая перекрывающиеся диапазоны, нормализацию пробелов и все случаи
некорректного ввода. Внешних зависимостей не добавляй — только stdlib.
