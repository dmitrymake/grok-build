# R7 — Adaptive topology

**Reference:** [`docs/ROADMAP.md#r7--adaptive-topology`](../ROADMAP.md#r7--adaptive-topology)

## Problem

Current topology is selected mainly from intent, complexity, and risk, with profile-driven widths and lens pools. Tasks within one intent can still differ substantially.

## Proposed shape

Drive bounded, explainable execution graphs from decomposability, sequentiality, oracle strength, tool density, and expected value, alongside existing policy signals.

## Validation

Compare fixed and adaptive graphs in the R1 matrix across controlled task-property changes. Measure success, cost, latency, unnecessary agents, and false blocks.

## Size

L

## Depends-on

R1 and R2.
